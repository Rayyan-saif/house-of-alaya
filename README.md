# The House of Alaya

Install with `pnpm install` and run with `pnpm dev`. Product data and image URLs are centralized in `app/[[...path]]/page.tsx`. Add the official logo under `public/branding/` and update the `Logo` component. The support email, WhatsApp placeholder and delivery settings can be changed in the same module. To deploy on Vercel, import the repository and use the standard Next.js settings.

Payments, authentication, tracking and form submission are clearly presented as frontend demo behavior until real services are connected.
